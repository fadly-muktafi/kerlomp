# Font (self-hosted)

File `.woff2` ini di-vendor agar `next dev` / `next build` tidak perlu mengunduh
dari `fonts.googleapis.com` (yang gagal di balik proxy kantor).

Semua font variable, subset latin. Sumber: Google Fonts. Lisensi: SIL Open Font
License 1.1 (OFL), bebas dipakai dan didistribusikan.

| File | Keluarga | Rentang weight |
|---|---|---|
| `plus-jakarta-sans-latin.woff2` | Plus Jakarta Sans | 200-800 |
| `space-grotesk-latin.woff2` | Space Grotesk | 300-700 |
| `geist-mono-latin.woff2` | Geist Mono | 100-900 |

Lisensi OFL: https://openfontlicense.org/
